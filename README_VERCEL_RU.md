# Интерактивная открытка — версия для GitHub и Vercel

Это готовая версия сайта на стандартном Next.js. В папке уже находятся весь код, изображения игрушек, открытки, диван, аквариум и персонаж.

## Важно

- Загружайте в GitHub содержимое этой распакованной папки, а не ZIP-файл.
- Папки `app` и `public`, а также файл `package.json` должны находиться в корне репозитория.
- В проекте нет секретных ключей и обязательных переменных окружения.
- Папку `node_modules` загружать в GitHub не нужно.

## Проверка на компьютере

Нужен Node.js версии 22 или новее.

```bash
npm install
npm run dev
```

После запуска откройте адрес, который будет показан в терминале — обычно `http://localhost:3000`.

## Загрузка в GitHub через GitHub Desktop

1. Распакуйте архив.
2. Откройте GitHub Desktop и войдите в аккаунт.
3. Выберите `File → Add Local Repository` и укажите эту папку.
4. Если программа сообщит, что папка ещё не является репозиторием, выберите `create a repository`.
5. Сделайте первый commit, например `Первая версия сайта`.
6. Нажмите `Publish repository`.
7. Репозиторий можно оставить приватным — Vercel получит доступ после подключения GitHub.

## Публикация на Vercel

1. Войдите на https://vercel.com через GitHub.
2. Нажмите `Add New… → Project`.
3. Найдите созданный репозиторий и нажмите `Import`.
4. Проверьте настройки:
   - Framework Preset: `Next.js`
   - Root Directory: `./`
   - Install Command: оставить автоматической или `npm install`
   - Build Command: оставить автоматической или `npm run build`
   - Output Directory: оставить пустым
   - Environment Variables: не нужны
5. Нажмите `Deploy`.
6. После успешной сборки откройте полученную ссылку вида `https://имя-проекта.vercel.app` в режиме инкогнито и с телефона.

## Обновление сайта

После изменений сделайте в GitHub Desktop новый commit и нажмите `Push origin`. Vercel автоматически обновит сайт по прежней ссылке.

## Если Vercel показывает ошибку

- `No Next.js version detected`: проверьте, что `package.json` находится в корне репозитория.
- Framework определился как `Other`: вручную выберите `Next.js`.
- Не отображаются изображения: проверьте, что папка `public` загружена целиком и находится в корне.
- Сайт просит войти в Vercel: в настройках проекта проверьте раздел `Deployment Protection`.
